つつじ version 1.1  -- 日本語機能表現の辞書

松吉俊、佐藤理史
2023/11/03 (マニュアル初版 2008/11/14)

1. 概要

「つつじ」は、名古屋大学 佐藤理史研究室において編纂された、日本語機能表現の辞書です。
自然言語処理における利用を想定し、さまざまな異形(異形態、異表記)を含む機能表現のリストを収録しています。

2. 配布ファイル

このディレクトリーには、以下のファイルが含まれています。

 - tsutsuji1.1.xml      つつじ version 1.1本体

 - schema.xsd, donID.xsd, dsjID.xsd, jptID.xsd, kkkID.xsd
                        妥当性検証のためのW3C XML Schemaファイル

 - connectID            左接続と右接続の記述に用いる接続IDのリスト

 - className            意味的等価クラスの日本語名リスト

 - className.db         上記のデータベースファイル(perlプログラム内で使用)

 - xml2list.perl        辞書本体から機能表現リストを生成するperlプログラム
                        
 - L[1-9].list          各階層における機能表現リスト

 - tsutsuji.csv         Excel用CSV (文字コードはシフトJISであり、改行コードはCRLF)

 - README.txt           このテキストファイル

3. つつじ本体

つつじ本体は、XML(eXtensible Markup Language)で記述されており、機能表現の形態階層構造を自然に表現するため、1つのエントリーは、次のような9階層の入れ子構造をしています。

<L1 属性名="値" ... >
 <L2 属性名="値" ... >
  <L3 ... >
     :
     <L9 ... >
     にたいして
     </L9>
     :
     <L9 ... >
     に対して
     </L9>    
     :
  </L3>
 </L2>
</L1>

それぞれの要素の属性に、次のような情報が記述されています。

- 意味的等価クラス・・・言い換え可能性に基づいて分類した機能表現のクラス
   [MCLASS属性]

 - 難易度・・・やさしい方から、A1, A2, B, C, Fの5段階
   [DIFFICULTY属性]

 - 文体・・・常体(normal)、敬体(polite)、口語体(colloquial)、堅い文体(stiff)の4種類
   [STYLE属性]

上位の階層に記述された情報は、下位の階層の機能表現に継承されます。
例えば、L2に記述された「意味的等価クラス」の情報は、下位のL3〜L9の機能表現に暗に継承されます。
しかしながら、これは絶対的なものではなく、下位の階層において新しい情報を記述することにより、上位の情報を上書きすることができます。

XMLファイルの文字コードは、UTF-8です。

つつじのXML形式についての詳細は、添付のW3C XML Schemaファイル"schema.xsd"をご参照ください。

4. 機能表現リストを生成するプログラム

つつじ本体から、任意の階層の機能表現リストをCSV形式で出力することができます。

出力行:
  表記,ID,読み,意味的等価クラス,難易度,文体,左接続,右接続,代表表記L9ID,稀,「日本語表現文型」掲載ページ,「現代語複合辞用例集」ID,「使い方の分かる類語例解辞典」ID,「日本語能力試験出題基準」ID, 意味的等価クラスの日本語名

出力行の例:
  に対して,0081P.1xx.01n02,にたいして,b21,A2,normal,1090,6H90,02,0,9-11,A52,S999-03N04,2C1.113n01,対象-指向-ニタイシテ類

プログラムの実行に必要なものは、以下のとおりです。
 - perl (perl 5.18.2で動作を確認)
 - perlモジュール"XML::LibXML"
 - perlモジュール"DB_File"

例えば、階層L9における機能表現リストを生成する場合、"L"オプションに"9"を指定して、次のようにプログラムを実行してください。

    % perl ./xml2list.perl -L 9 > newlist

"s"オプションを指定すると、機能表現の表記を、"."で短単位に区切ります。
例えば、次のようにプログラムを実行してください。

    % perl ./xml2list.perl -L 9 -s > newlist
