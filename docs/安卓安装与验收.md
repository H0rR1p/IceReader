# 冰读 Android 0.4.0

## 安装

使用签名 Release 文件 `IceReader-0.4.0.apk`。要求 Android 10 或更高版本、arm64-v8a 或 x86_64 处理器。允许对应文件管理器“安装未知应用”后打开 APK。应用图标使用作者绘制的琪露诺 Logo。

首次启动会在应用私有目录安装 core 字典和对应源码包，请预留至少 1 GiB 可用空间，书籍另计。应用被卸载会删除私有数据，卸载前先导出备份。同一签名的后续正式版本支持覆盖安装；Debug 证书与 Release 证书不同，不能相互覆盖。

## 使用与能力边界

- 本机资料空间不需要密码；可以设置昵称和头像。云账号使用现有 HTTPS 服务。
- EPUB、文本导入、切句切词、已有词义、词卡、复习、学习统计和阅读位置保存在本机。AI 释义、语法与修正需要用户配置 AI 密钥并联网。
- 学习数据可立即同步、拉取和处理冲突。完整书籍正文、图片、切分和译文通过书籍分享包或数据迁移包传输。
- 导出使用 Android 系统保存窗口；取消保存不会删除原书。书籍导入使用系统文件选择器。
- 阅读页提供“保持亮屏”；云端页面提供按账号保存的后台同步开关。后台同步由 WorkManager 调度，约 30 分钟一次，受系统电量和网络策略限制，不能承诺准点执行。
- Cookie、刷新凭据和 AI 密钥由 Keystore 加密保存，不通过 WebView 向页面公开 Cookie。安卓加密密钥不进入备份；换设备后重新填写 AI 密钥。
- 不包含 YMM4、配音桥、语音包、播放读音、句子配音或 Logo 点击音频。

## 构建

工具版本：Node 24、JDK 21、Gradle 8.14、Android SDK 36 / Build Tools 36.0.0、NDK r27d、64 位 Python 3.12、Capacitor 8.5.0、Chaquopy 17.0.0。

```powershell
$env:JAVA_HOME = '你的 JDK 21 目录'
$env:ANDROID_HOME = '你的 Android SDK 目录'
$env:ANDROID_NDK_HOME = '你的 NDK r27d 目录'
$env:BINGDU_BUILD_PYTHON = '你的 Python 3.12/python.exe'
$env:BINGDU_ANDROID_KEYSTORE = '你的私有签名密钥.jks'
$env:BINGDU_ANDROID_STORE_PASSWORD = '密钥库密码'
$env:BINGDU_ANDROID_KEY_ALIAS = 'icereader'
$env:BINGDU_ANDROID_KEY_PASSWORD = '签名密钥密码'
python -m pip install packaging
npm run android:build
```

脚本按哈希验证 Sudachi core 20250515 和官方 SQLite 3.46.1 源码，生成两种 ABI 的 FTS5 库、内置界面、许可及对应源码，然后签名并验证 APK。npm 依赖以 package-lock.json 为准；Python 运行依赖固定在 requirements-android.txt。Maven 实际解析版本与原始源码 JAR 哈希在 third_party_licenses/android/inventory.json。

构建输出：`build/android-release/`。签名密钥与密码不得提交 Git，必须独立备份，否则无法发布同签名升级。

## 验收记录

开发验收设备为 Android 15 / API 35 的 Pixel Tablet x86_64 模拟器，2560×1600 屏幕；APK 同时包含 arm64-v8a。真实 ARM 平板、Android 10 和 16 KiB 页系统尚未实机验证，不能用模拟器结果代替这些设备的验收。

已完成：

- 52 项 Python 回归测试：账号、头像、刷新凭据、词卡、复习、迁移、AI 修正、JSON 返回解析、EPUB 主动内容过滤及按用户加密密钥适配。
- 200 条构造日语文本与桌面 SudachiPy core 对照，逐词比较词形、基本形、读音、词性和偏移一致。这些样本由 10 类句式变化构成，不代表自然语言全覆盖。
- 10 个双章 EPUB 构造样本在安卓本地导入；覆盖 ruby、换行、日文文件名和插图。
- 原生 SQLite FTS5 搜索、加入词卡和一次复习计算；安卓所有数据库连接统一使用同一个原生 SQLite 引擎，避免混用引擎破坏进程内 WAL 锁。
- 系统保存窗口成功导出迁移 ZIP；应用进程停止并重新启动后仍恢复已选句子；进入设置后的继续阅读恢复同句。
- 导出的迁移包在另一独立本机账号载入，保留书籍、5 个句子、65 个词元和学习词卡；迁移索引重建使用原生 FTS5 连接。
- 初始化切词并完成测试后，模拟器观测总 PSS 约 189 MiB；这是一次测量，不是内存上限承诺。
- WorkManager 后台任务已登记；自动同步开关按用户保存。

外部依赖验收限制：最终构建时，构建机与模拟器访问公网 HTTPS 服务均未成功（连接被重置或超时），因此本次没有完成真实云账号联网验收。此前提供商列表为空，实际第三方登录需要服务端配置后验收；真实 AI 请求需要用户 API Key。现有认证、同步、限流和 AI 错误处理通过领域回归测试，不能表述为已验证所有外部供应商。

最终 APK 的签名、权限、安装及布局验证结果和 SHA-256 随构建产物提供。源码与许可可在应用内下载；Logo 属东方 Project 非官方二次创作，详见 NOTICE.md。
